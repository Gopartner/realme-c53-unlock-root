 2. CARA MASUK BROM (paling penting)
    -> TIDAK ADA SCRIPT. Ini gerakan tangan di HP.
============================================================
Cara 1 (biasa):
  1. Matikan HP total (jika menyala).
  2. Tekan DAN TAHAN tombol: Volume UP + Volume DOWN + Power.
  3. Tahan terus sambil mencolok kabel USB ke PC.
  4. Lepas tombol setelah 5-10 detik (Windows bisa bunyi 'device connected').

Cara 2 (jika layar/HP mati total):
  - Pastikan HP benar-benar off.
  - Colok USB, lalu tekan & tahan kombinasi tombol yang sama
    selama +- 5-10 detik.

Setiap fase baru = masuk BROM ULANG dulu.
KECUALI fase 5 (flash_phase4_finalize.bat) yang reset sendiri.

============================================================
 10. PANDUAN ERROR SPESIFIK
     -> TIDAK ADA SCRIPT. Referensi bila error.
============================================================

A) "bad length (8191, expected 63494)" + "timeout reached"
   Arti: FDL2/USB putus di tengah operasi (biasanya saat baca
         blok besar, misal super.img).
   Penyebab umum: port USB 3.0 / hub / kabel jelek / kontak.
   Solusi:
     - Cabut kabel, matikan HP.
     - Masuk BROM ulang.
     - Ulangi script yang sama (aman: tiap fase erase dulu).
     - Pakai port USB 2.0 langsung di motherboard.
     - Coba kabel lain / port lain.
   Jika terjadi di backup_a15_fresh.bat: lewati saja (opsional).

B) "GAGAL!" muncul di akhir script
   Arti: spd_dump keluar dengan error code.
   Solusi: masuk BROM ulang, ulangi fase yang sama. Periksa log
   spd_dump (folder Log\ di 01_alat\spd_tools\).

C) Windows tidak mendeteksi device (tidak ada bunyi connect)
   Solusi:
     - Pastikan kombinasi tombol benar (UP+DOWN+Power).
     - Tahan lebih lama (10-15 detik).
     - Coba port USB lain.
     - Cek Device Manager: 'LGE Mobile' / 'SPD' / 'Qualcomm' device
       muncul saat BROM.

D) Error di verify: FAIL
   Solusi: flash ulang partisi yang bersangkutan (ulangi fase),
   lalu verify lagi.

E) HP boot ke A14 tapi WiFi/sinyal/IMEI bermasalah
   Arti: NV (l_fixnv1_a/prodnv) mungkin perlu di-flash ulang.
   Solusi: ulangi fase 3 (flash_phase2_modem.bat) lalu boot lagi.

F) HP tidak boot sama sekali setelah fase 5
   Solusi:
     - Masuk BROM, jalankan restore_a15.bat (bagian 9).
     - Jika A15 juga tidak boot: masalah hardware/power.
